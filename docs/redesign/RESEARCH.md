# Home page research: Shopify, BigCommerce, Wix, Squarespace, Webflow, Stripe, Linear, Vercel

Viewed 2026-11-15 in Chrome (desktop, UK/India locale redirects as served). For each site we read the hero, the order of headings, tabs and videos on the page, and looked at the hero. Text is summarised, never copied; nothing here is used one-to-one.

## Per site

### Shopify
- **Order:** dark announcement-style nav → hero with full-bleed video and one CTA → "sell everywhere" tabbed showcase (online, in person, AI, social) → AI assistant feature → "grow globally" / "entrepreneur to enterprise" cards → app ecosystem (wall of app icons, "21,000+ apps") → checkout and reliability proof (conversion and uptime stats) → developer section → final CTA → big footer.
- **Components:** mega menu grouped by job (Build, Sell, Market, Manage), tabbed channel showcase, bento cards, logo/app icon wall, stats band, quote card with avatar, final CTA band.
- **Assets:** looping product videos (10 on the page), real merchant photography, product UI cut-outs inside cards, dark gradient backgrounds with a purple glow.
- **Copy:** short ambitious headline, one-line sub naming the category ("commerce platform"), single CTA "Start for free", trial terms beside it.

### BigCommerce
- **Order:** hero (headline + paragraph + one CTA) → "solutions for every kind of brand" → design flexibility → global selling → customer proof → AI shopping → B2B → payments → "launch your store today" + "no credit card" → integrations/stack → expert services → results with sub-products → news and podcast → footer.
- **Components:** mega menu split by product family, alternating text/image rows, logo strip, integration logo grid, trial CTA band repeated mid-page.
- **Assets:** product UI screenshots in browser frames, lifestyle photos, flat icons.
- **Copy:** benefit headlines in "verb + outcome" form; reassurance microcopy under CTAs ("No credit card. No pressure.").

### Wix
- **Order:** hero (headline, "Start for free, no credit card" line, one CTA) → AI builder demo video → solutions grid (eCommerce, scheduling, payments… 8 tiles) → templates gallery → customisation features (4 cards) → AI assistant → foundations: reliability, security, expert support, functionality → domains → analytics → business tools → marketing tools (5 cards) → mobile app + dashboard → "you're in good company" (customer logos/stories) → footer.
- **Components:** mega menu with columns and featured card, solution tile grid, template carousel, feature card groups, trust band (reliability/security/support), testimonial row.
- **Assets:** 19 short looping videos of the editor, device mockups, colourful UI cut-outs.
- **Copy:** outcome headline ("create your future"), risk-reversal sub, CTA "Get Started".

### Squarespace
- **Order:** hero video + headline + one CTA → "grow your business" use-case tiles (8) → "everything on one platform" feature grid (9) → AI builder + templates → domains → "trusted by 14 million" stat → customer site gallery → how to build a website (steps) → FAQ → 24/7 support → final free-trial CTA.
- **Components:** carousel with previous/next controls, use-case tiles, feature grid, big stat, site gallery, numbered steps, FAQ accordion, support band, final CTA.
- **Assets:** 12 videos, full-bleed customer website screenshots, very little illustration.
- **Copy:** short emotional headline, "start for free, no card" sub, uppercase CTA with arrow.

### Webflow
- **Order:** hero (headline, one-sentence sub naming the outcome "drives real revenue", two CTAs: start + talk to sales) → product video → "300,000+ brands" logo wall and case-study tabs → growth features → recent updates → footer with many columns.
- **Components:** mega menu with sub-panels and back button, two-CTA hero, logo marquee, tabbed case studies with metrics, card grid for updates.
- **Assets:** product UI recordings, abstract gradient and 3D renders behind UI, customer logos.
- **Copy:** short verb headline + sub with a concrete benefit; secondary CTA for sales.

### Stripe
- **Order:** announcement bar → nav with mega menus (Products, Solutions, Developers, Resources) → hero with animated gradient ribbon, live counter, two CTAs (Get started, Sign up with Google) → logo wall → "solutions for every business model" (6 product tiles with UI) → "backbone of global commerce" stats → customer stories by segment (tabs/cards) → developer section (code, integrations, scale) → news cards → footer.
- **Components:** animated gradient background, logo row, product tiles with mini UI, big stats, customer cards with numbers, code snippet panel.
- **Assets:** abstract gradient art, crisp product UI fragments, logos; no stock photos in the hero.
- **Copy:** long, precise headline naming category and outcome; CTA pair "Get started" + social sign-up.

### Linear (polish reference)
- **Order:** hero (short category headline, one-line sub) → large app UI shown in a dark frame → feature chapters (intake, planning, AI, build) each with UI → changelog → final CTA → footer.
- **Components:** chaptered feature sections, very large product screenshots, subtle grid lines and glows.
- **Type:** Inter variable at 64px, weight 510, tracking −0.022em: confident without being heavy.
- **Copy:** one sentence says what it is and for whom.

### Vercel (polish reference)
- **Order:** hero with two CTAs (Deploy now, Talk to sales) → capability sections with diagrams → "recently shipped" → customer section → footer with many grouped columns incl. Legal & Trust and Social.
- **Type:** Geist Sans 64px, weight 400, tracking −0.06em; monochrome palette with one accent.
- **Assets:** diagrams and UI, thin borders, grid backdrops, gradient glows.

## Motion, theme and type (second visit, 2026-11-15)

Measured in Chrome by scrolling each page top to bottom and listing every running animation (`document.getAnimations()`), sticky elements, videos, canvases, the header's blur and the headline size.

| Site | Headline | Theme | Motion seen | Assets |
| --- | --- | --- | --- | --- |
| Vercel | 64px, weight 400, tracking −0.06em (Geist) | white, black alt sections | opacity fade-ins on scroll (11), sticky header, one canvas | diagrams, product UI, grid lines |
| Shopify | 96px, tracking −0.02em | dark sections with glows | translate + opacity reveals (150+), infinite horizontal marquee (`scroll-x`, 60 runs), floating glow/orbit loops, 10 looping videos, sticky header | video, product UI, merchant photos |
| Stripe | 42px multi-line headline | white with animated gradient | keyframed opacity/transform sequences (200+), live digit counter in the hero (each digit its own element), scroll detection, 5 canvases (gradient + globe) | gradient art, UI fragments, logo row |
| Linear | 64px | near-black `#08090A`, transparent header with `blur(20px)` | looping dot-grid and border-sweep animations, staged UI entrances, no sticky pinning | large app UI in dark frames, dot grids |
| Webflow | 80px | near-black `#080808` | marquee cards fading in (150+), fade and scale reveals, 6 videos, 1 canvas | UI recordings, 3D renders, logo marquee |
| BigCommerce | 40px | white | none measured; the site showed a bot check ("Just a moment…") on this visit, which we did not bypass, so this row uses the first visit only | screenshots in browser frames |

Repeated patterns we adopt (4+ sites): large tight headlines (64–96px), dark surfaces with soft glow accents (Shopify, Linear, Webflow, Vercel sections), fade-and-rise reveals on scroll, an infinite logo marquee under the hero (Shopify, Webflow, Stripe, Vercel customers), floating UI cards over the hero visual (Shopify, Stripe, Linear), sticky header that turns translucent/blurred, and number emphasis in stats (Stripe counter, Shopify stats). Videos are common but we use animated UI instead (lighter, no recording needed).

## Visual takeaways
- Restraint: white or near-white surfaces, one strong brand colour, gradients only behind product visuals and the final CTA.
- Large, medium-weight headlines (Linear 510, Vercel 400) read as more premium than very heavy display type.
- Product UI is the hero; illustrations play a supporting role.
- Generous whitespace (120–160px between sections), a 12-column grid, 1200–1280px content width, thin 1px borders, soft long shadows.
