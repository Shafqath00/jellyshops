# Jelly Links dashboard: visual identity notes

Studied 2026-11-14 in the owner's signed-in Jelly Links dashboard (Dashboard and Products pages), values read from the computed styles. Screenshots of that account were not saved to the repo because they show the owner's handle and avatar.

## What it looks like

| Area | Observed |
| --- | --- |
| Page background | Warm stone `#F3F2EC` behind everything |
| Content canvas | A floating panel `#FAFAF7`, 24px corners, 1px border `#E6E3DA`, very soft shadow `0 1px 2px rgba(10,10,10,.03)`, inset ~8px from the window edges. The header row lives inside this panel |
| Sidebar | No background of its own (sits on the stone colour). Big logo top left. Section labels in small uppercase letter-spaced text with a dot (`● BUILD`, `● GROW`, `● EARN`). Each item has a small coloured icon tile (lime, blue, pink, orange). Active item: white pill, 12px corners, icon tile turns black with a lime glyph. Account card pinned at the foot with a lime "PRO" chip |
| Header | Page icon tile + page title (19px, weight 680, tracking −0.025em), a segmented switch in the middle (pill track `#EFEDE6` with inset shadow, active segment black with white text), account pill on the right |
| Colour | Ink `#0A0A0A` text; warm muted text `#6B675F`; nav text `#2B2925`; signature lime `#C9FF18` (main buttons, live chips, progress, ticks); blue `#2F5BFF`, pink `#F3A5CF`, peach as secondary accents; success panel in pale green |
| Watercolour | Stat cards carry a soft, blurred colour wash in one corner (lime, blue, pink, peach), plus a glossy coloured icon tile (`linear-gradient(rgba(255,255,255,.28), transparent 55%)` over the tile colour). Never behind text |
| Hero | Black welcome card with a dotted texture, date eyebrow in mono uppercase, large greeting (≈40px bold), lime main button, ghost pill buttons (white 7% fill, white 15% border) |
| Cards | White, 16px corners, 1px border `#E6E3DA`, inner top highlight + small drop shadow, 20px padding |
| Buttons | Pills (fully round). Lime filled with ink text for the main action; black filled for strong secondary ("Edit profile →"); outlined white pill for the rest. 13.5px weight 600 |
| Tabs | Pills: active black with white text, inactive plain text |
| Tables | Small uppercase letter-spaced column headings on a pale warm strip; roomy rows (≈80px with thumbnails); lime toggle switches; quiet icon actions at the row end |
| Typography | Custom "Link Sans" (geometric grotesque) for UI, a mono for eyebrows; headings heavy (600–700) with negative tracking; body 13–15px |
| Personality | Friendly mascot illustrations in empty/loading moments; plain, warm wording |

## What makes it feel like one product

1. Warm neutrals instead of cold greys everywhere.
2. One loud colour (lime) used sparingly for "go" moments.
3. Pills for anything you press; generous corners for anything that holds content.
4. Coloured icon tiles give each area a recognisable colour.
5. Soft watercolour washes only on summary tiles and the hero.

## What Jelly Shop takes, and what it changes

| Take | Change for Jelly Shop's own identity |
| --- | --- |
| Warm stone page, floating canvas, header inside the canvas | – |
| Dotted uppercase section labels, coloured icon tiles in the sidebar | Tiles are tinted (soft colour + coloured glyph) rather than solid, to stay calm across many nav items |
| Pill buttons, 16px cards, 24px canvas | – |
| Watercolour corner washes on stat tiles | Used on Home tiles and the welcome card only |
| Lime as the family colour | Lime is Jelly Shop's **highlight** (brand mark, active nav tile, progress, success ticks, chart highlight); Jelly Shop's **action** colour is Jelly blue `#2F5BFF` (kept from the owner's earlier choice), so the shop reads as a sibling, not a copy |
| Black active pills for tabs and segmented choices | – |
| Link Sans | Not available to us; Inter (already self-hosted) with tighter tracking on headings. No new font dependency |
